Windows 실기기 점검에서 찾은 결함 두 가지를 고쳤습니다. macOS 는 속성 패널의 숫자 칸 높이만 바뀌었습니다(아래 "두 OS 공통").

## 고친 점 (Windows)

### 좌표 선택이 배율 100% 가 아닌 화면에서 엉뚱한 곳을 누르던 문제
디스플레이 배율(설정 → 디스플레이 → 배율)이 100% 가 아닌 화면에서는, 좌표 선택으로 찍은 점과 Mouse Click 단계가 누르는 점이 달랐습니다. 배율 125% 에서는 화면의 (805, 455) 지점을 찍으면 (644, 364) 지점을 눌렀습니다(실제 픽셀 기준, 왼쪽 위로 약 160px). 이제 좌표 선택은 클릭에 쓰는 화면의 실제 픽셀 좌표를 돌려줍니다. 그래서 배율이 100% 가 아니면 좌표 선택 창에 보이는 숫자가 전보다 큽니다.

> **좌표를 다시 찍어야 합니다.** 배율이 100% 가 아닌 Windows 화면에서 0.1.1 이하의 좌표 선택으로 찍은 Mouse Click 좌표는 엉뚱한 곳을 누릅니다. 0.1.2 에서 다시 찍으세요. 배율 100% 화면에서 찍은 좌표와 macOS 에서 찍은 좌표는 그대로 맞습니다.

### 저장한 시나리오에서 고른 이미지가 "missing" 으로 보이던 문제
시나리오를 한 번 저장한 뒤 Browse 나 끌어 놓기로 고른 이미지, 시나리오와 다른 드라이브에 있는 이미지가 카드에 missing 으로 보이고 실행이 "Template image file not found" 로 멈췄습니다. 이제 `C:\...`, `C:/...`, `\\서버\공유\...` 같은 경로를 그대로 찾습니다. 0.1.1 에서 missing 으로 보이던 시나리오도 0.1.2 로 열면 이미지를 찾습니다.

## 고친 점 (두 OS 공통)
- 속성 패널의 숫자 칸(Press duration, Timeout, Confidence 등)이 옆의 입력 칸·선택 칸보다 2px 낮게(30px) 보였습니다. 이제 모두 32px 로 맞습니다.

## 알아 둘 점 (Windows)
- Key Input 단계의 `menu` 와 `shift+f10` 은 Windows 에서 **오른쪽 클릭과 같은 메뉴**를 엽니다.
- `cmd` 가 든 단계(예: `cmd+x`)는 Windows 에서 **Win 키** 조합입니다. Win+X 는 시작 버튼의 오른쪽 클릭 메뉴, Win+V 는 클립보드 기록 창을 엽니다. macOS 에서 Cmd, Windows 에서 Ctrl 을 누르려면 `cmd_or_ctrl` 을 쓰세요.

## 시나리오 파일 호환
- 파일 형식은 0.1.1 과 같습니다. 0.1.1 과 그대로 주고받을 수 있습니다(위의 좌표 다시 찍기는 따로 확인하세요).

## 이전 버전에서 업데이트
- **Windows**: 새 `setup.exe`를 실행하면 기존 설치 위에 덮어씁니다. 포터블은 새 zip을 풀어 쓰면 됩니다.
- **macOS**: DMG의 `ActionMacro`를 `Applications`로 끌어 놓고 **대치**를 고릅니다. 첫 실행 허용(아래 2번)을 다시 해야 합니다. 앱이 임시(ad-hoc) 서명이라 권한도 다시 물을 수 있습니다. 이때는 **시스템 설정 → 개인정보 보호 및 보안**의 각 목록에서 옛 `ActionMacro` 항목을 지우고 다시 허용합니다.

## 설치와 첫 실행

### macOS (12 이상)
1. DMG를 열어 `ActionMacro`를 `Applications`로 끌어 놓습니다. 포터블은 zip을 풀어 `ActionMacro.app`을 원하는 폴더에 둡니다. DMG 안에서 바로 실행하지 마세요.
2. 처음 열면 *"Apple could not verify “ActionMacro” is free of malware…"* 경고가 나오고 열리지 않습니다. 앱에 Apple 개발자 서명과 공증이 없어서이고, 앱이 손상된 것은 아닙니다. 아래 둘 중 하나로 한 번만 허용하면 됩니다.
   - **시스템 설정에서**: 경고 창에서 **완료**를 누르고, **시스템 설정 → 개인정보 보호 및 보안** 맨 아래의 **그래도 열기**를 누른 뒤 암호로 확인합니다. 이 버튼은 방금 열려다 막힌 앱에만 한동안 보이므로, 안 보이면 앱을 한 번 더 열어 본 뒤 확인하세요.
   - **터미널에서**: 인터넷에서 받은 파일에 붙는 격리 표시를 지웁니다. 다른 폴더에 두었다면 경로를 그 위치로 바꿉니다. 그다음에는 평소처럼 열립니다.

     ```bash
     xattr -dr com.apple.quarantine /Applications/ActionMacro.app
     ```
3. **시스템 설정 → 개인정보 보호 및 보안**에서 `ActionMacro`를 허용합니다.
   - **손쉬운 사용**: 마우스·키보드 입력
   - **입력 모니터링**: 긴급 정지 단축키(Esc · Ctrl+Shift+S)
   - **화면 및 시스템 오디오 녹음**: 이미지 대기와 좌표 선택 돋보기

   빠진 권한은 앱의 **⋯ → Permissions…**에서 확인하고 설정 화면을 바로 열 수 있습니다.

### Windows (10/11, 64비트)
1. `setup.exe`를 실행합니다. 기본은 현재 사용자 설치라서 관리자 권한이 필요 없습니다. 포터블은 zip을 풀고 `ActionMacro.exe`를 실행합니다.
2. 코드 서명이 없어서 SmartScreen이 막으면 **추가 정보 → 실행**을 누르세요.
3. 관리자 권한으로 도는 프로그램(일부 게임·에뮬레이터)에 입력하려면 ActionMacro도 관리자 권한으로 실행해야 합니다.

## 확인한 것
- 자동 테스트 1205개 통과(macOS, 화면 없는 환경, 입력·캡처는 가짜).
- 이번에는 같은 자동 테스트를 Windows(GitHub Actions 러너)에서도 돌렸습니다. 1197개가 통과했고, Windows 에 해당하지 않는 11개는 건너뛰었습니다. 나머지 1개는 Windows 의 파일 잠금 방식 때문에 예상 실패로 둡니다(앱은 한 시나리오 파일을 동시에 읽고 쓰지 않습니다).
- 모든 패키지는 빌드 직후 자체 점검을 통과한 것만 올렸습니다.
- **Windows 10 실기기 점검**(배율 100% · 125%, Microsoft 한국어 IME): 클릭 오차 0px, 배율 125% 에서 좌표 선택 → 클릭 오차 1px 미만, 조합키, 긴급 정지(버튼·키 3~5ms 안에 놓음), 실제 메인 창에서 실행.
- 0.1.1 에서 확인하지 못했던 **Windows 글자 입력**도 실기기에서 확인했습니다. 한/영이 영문일 때, 한글일 때, Caps Lock 을 켰을 때, 한글 + Caps Lock 일 때 모두 `myid123`, `Ab1 x_Y!@`, `안녕하세요 홍길동 id123` 이 적은 대로 들어갔습니다. 0.1.1 포터블 패키지로 메모장에 입력해 본 것도 모두 맞았습니다.
- macOS(Apple Silicon) 실기기 점검 18단계 통과: 주 모니터와 왼쪽 보조 모니터(음수 좌표)에서 클릭 오차 0px, 좌표 선택이 찍은 점을 그대로 돌려줌.

## 알려진 제한
- Windows 배율 150% 와 여러 모니터(음수 좌표)는 아직 실기기에서 확인하지 않았습니다.
- Windows 배율 125% 에서 한 번, 글자 입력 단계가 첫 글자만 입력한 일이 있었습니다. 같은 PC 에서 다시 돌린 9번은 모두 맞았고 원인은 아직 모릅니다. 글자가 덜 들어가면 알려 주세요.
- macOS와 Windows 모두 코드 서명이 없습니다(위의 첫 실행 안내 참고).
- Intel Mac 패키지는 0.1.1부터 내지 않습니다. Intel Mac에서는 0.1.0을 쓰거나 소스에서 실행하세요(README 참고).
- Linux 패키지는 없습니다.
- 백그라운드 실행(`--headless`)은 Windows 패키지에서 콘솔 출력이 보이지 않습니다. 명령줄로 쓰려면 소스에서 설치하세요(README 참고).

포함된 서드파티 소프트웨어와 라이선스는 앱 안의 `THIRD_PARTY_NOTICES.txt`에 있습니다.
