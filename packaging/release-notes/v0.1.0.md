ActionMacro의 첫 공개 릴리스입니다. 마우스 클릭, 키 입력, 대기, 이미지 대기 단계를 카드로 쌓아 시나리오를 만들고 실행하는 macOS · Windows 데스크톱 매크로 도구입니다.

## 다운로드

| OS | 설치본 | 포터블 (설치 없이 실행) |
|---|---|---|
| macOS · Apple Silicon (M1 이후) | `ActionMacro-0.1.0-macos-arm64.dmg` | `ActionMacro-0.1.0-macos-arm64-portable.zip` |
| macOS · Intel | `ActionMacro-0.1.0-macos-x64.dmg` | `ActionMacro-0.1.0-macos-x64-portable.zip` |
| Windows 10/11 (64비트) | `ActionMacro-0.1.0-windows-x64-setup.exe` | `ActionMacro-0.1.0-windows-x64-portable.zip` |

받은 파일은 `SHA256SUMS.txt`로 확인할 수 있습니다.

## 설치와 첫 실행

### macOS (12 이상)
1. DMG를 열어 `ActionMacro`를 `Applications`로 끌어 놓습니다. 포터블은 zip을 풀어 `ActionMacro.app`을 바로 실행합니다.
2. 처음 열 때 macOS가 막습니다. 앱에 Apple 개발자 서명과 공증이 없기 때문입니다. **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 **그래도 열기**를 누르세요.
3. **시스템 설정 → 개인정보 보호 및 보안**에서 `ActionMacro`를 허용합니다.
   - **손쉬운 사용**: 마우스·키보드 입력
   - **입력 모니터링**: 긴급 정지 단축키(Esc · Ctrl+Shift+S)
   - **화면 및 시스템 오디오 녹음**: 이미지 대기와 좌표 선택 돋보기

   빠진 권한은 앱의 **⋯ → Permissions…**에서 확인하고 설정 화면을 바로 열 수 있습니다.

### Windows (10/11, 64비트)
1. `setup.exe`를 실행합니다. 기본은 현재 사용자 설치라서 관리자 권한이 필요 없습니다. 포터블은 zip을 풀고 `ActionMacro.exe`를 실행합니다.
2. 코드 서명이 없어서 SmartScreen이 막으면 **추가 정보 → 실행**을 누르세요.
3. 관리자 권한으로 도는 프로그램(일부 게임·에뮬레이터)에 입력하려면 ActionMacro도 관리자 권한으로 실행해야 합니다.

## 주요 기능
- **시나리오 편집기**: 단계를 카드로 추가, 끌어서 순서 변경, 복제, 켜기/끄기. 각 카드는 "Click left at (1280, 720)"처럼 한 문장으로 요약됩니다.
- **단계 종류**: 마우스 클릭(여러 번, 간격), 키 입력(조합 키, 누르기/누른 채로/떼기), 고정 대기, 이미지가 나타날 때까지/사라질 때까지 대기(일치율, 제한 시간, 영역 지정).
- **정밀 좌표**: 여러 모니터, 왼쪽·위쪽 보조 모니터의 음수 좌표, Retina/HiDPI 배율 보정. 화면에서 좌표를 바로 고르는 돋보기 선택기.
- **안전한 실행**: 반복 횟수 또는 무한 반복, 일시정지, 긴급 정지(Esc · Ctrl+Shift+S). 정지하면 눌려 있던 버튼과 키를 바로 놓습니다.
- **시나리오 파일**: JSON으로 저장하고 Mac과 Windows 사이에서 그대로 열 수 있습니다. 최근 파일 목록을 제공합니다.
- **화면**: Postman 스타일의 다크 작업 공간, 단계 속성 패널, 레벨별로 거르는 콘솔, 실행 상태 표시줄.

## 확인한 것
- 자동 테스트 1165개 통과(화면 없는 환경, 입력·캡처는 가짜).
- 모든 패키지는 빌드 직후 자체 점검을 통과한 것만 올렸습니다. 점검 항목은 OpenCV 이미지 매칭, 입력 백엔드, 키보드 배열 읽기, 메인 창 생성입니다.
- macOS(Apple Silicon) 실기기 점검 16단계 통과: 클릭 오차 0px(모니터 2대, 음수 좌표 포함), 조합 키, 실행 중 긴급 정지, 좌표 선택기.
- Windows 패키지는 빌드와 자체 점검까지 확인했고, 실기기에서는 아직 돌려 보지 않았습니다.

## 알려진 제한
- macOS와 Windows 모두 코드 서명이 없습니다(위의 첫 실행 안내 참고).
- macOS 앱은 임시(ad-hoc) 서명이라, 새 버전으로 바꾸면 권한을 다시 허용해야 할 수 있습니다. 이때는 목록의 옛 `ActionMacro` 항목을 지우고 다시 허용합니다.
- Linux 패키지는 없습니다.
- 백그라운드 실행(`--headless`)은 Windows 패키지에서 콘솔 출력이 보이지 않습니다. 명령줄로 쓰려면 소스에서 설치하세요(README 참고).

포함된 서드파티 소프트웨어와 라이선스는 앱 안의 `THIRD_PARTY_NOTICES.txt`에 있습니다.
