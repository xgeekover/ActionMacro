macOS 에서 창 맨 위가 한 줄로 바뀌었습니다. 지금까지는 macOS 타이틀바 아래에 앱 상단바가 따로 있어서, "ActionMacro"와 파일 이름이 두 번 보였습니다. Windows 는 바뀌지 않았습니다.

## 바뀐 점 (macOS)

### 상단바가 타이틀바 자리를 차지합니다
VS Code 처럼 앱 상단바가 창 맨 위에 붙고, 닫기·최소화·확대 버튼이 상단바 왼쪽 끝에 들어갑니다. 위쪽이 타이틀바 28pt + 상단바 44px 에서 한 줄 38pt 로 줄어, 내용이 34pt 더 보입니다.

- 상단바 빈 곳(글자 위 포함)을 끌면 창이 움직입니다. 메뉴와 버튼은 전처럼 눌립니다.
- 빈 곳을 더블클릭하면 **시스템 설정 → 데스크탑 및 Dock**의 "윈도우 제목 막대를 이중 클릭하여" 설정대로 확대하거나 최소화합니다.
- 창 이름은 그대로 있습니다. Dock, 미션 컨트롤, Window 메뉴에서 보입니다.

### macOS 버전에 따라 다릅니다
상단바를 타이틀바 자리에 두려면, 그 줄을 누른 클릭이 앱에 와야 합니다. macOS 버전마다 이 점이 달라서, 앱이 창을 띄울 때마다 확인합니다. 클릭이 앱에 오지 않는 버전에서는 0.1.2 와 같은 모습(타이틀바 아래 상단바)을 씁니다. 그래야 상단바의 버튼이 눌립니다.

| macOS | 모습 |
|---|---|
| 27 | 한 줄 (실기기 확인) |
| 15 | 0.1.2 와 같음 (자동 테스트로 확인) |
| 그 밖의 버전 | 위 확인 결과에 따라 둘 중 하나. 26 은 아직 확인하지 않았습니다 |

0.1.2 와 같은 모습을 쓰는 버전에서는 창이 뜰 때 한 번 깜빡일 수 있습니다.

## 이전 버전에서 업데이트
- **Windows**: 새 `setup.exe`를 실행하면 기존 설치 위에 덮어씁니다. 포터블은 새 zip을 풀어 쓰면 됩니다.
- **macOS**: DMG의 `ActionMacro`를 `Applications`로 끌어 놓고 **대치**를 고릅니다. 첫 실행 허용(아래 2번)을 다시 해야 합니다. 앱이 임시(ad-hoc) 서명이라 권한도 다시 물을 수 있습니다. 이때는 **시스템 설정 → 개인정보 보호 및 보안**의 각 목록에서 옛 `ActionMacro` 항목을 지우고 다시 허용합니다.

## 설치와 첫 실행

### macOS (12 이상)
1. DMG를 열어 `ActionMacro`를 `Applications`로 끌어 놓습니다. 포터블은 zip을 풀어 `ActionMacro.app`을 원하는 폴더에 둡니다. DMG 안에서 바로 실행하지 마세요.
2. 처음 열면 *"Apple could not verify “ActionMacro” is free of malware…"* 경고가 나오고 열리지 않습니다. 앱에 Apple 개발자 서명과 공증이 없어서이고, 앱이 손상된 것은 아닙니다. 아래 둘 중 하나로 한 번만 허용하면 됩니다.
   - **시스템 설정에서**: 경고 창에서 **완료**를 누르고, **시스템 설정 → 개인정보 보호 및 보안** 맨 아래의 **그래도 열기**를 누른 뒤 암호로 확인합니다. 이 버튼은 방금 열려다 막힌 앱에만 한동안 보이므로, 안 보이면 앱을 한 번 더 열어 본 뒤 확인하세요.
   - **터미널에서**: 인터넷에서 받은 파일에 붙는 격리 표시를 지웁니다. 다른 폴더에 두었다면 경로를 그 위치로 바꿉니다. 그다음에는 평소처럼 열립니다.

     ```bash
     xattr -dr com.apple.quarantine /Applications/ActionMacro.app
     ```
3. **시스템 설정 → 개인정보 보호 및 보안**에서 `ActionMacro`를 허용합니다.
   - **손쉬운 사용**: 마우스·키보드 입력
   - **입력 모니터링**: 긴급 정지 단축키(Esc · Ctrl+Shift+S)
   - **화면 및 시스템 오디오 녹음**: 이미지 대기와 좌표 선택 돋보기

   빠진 권한은 앱의 **⋯ → Permissions…**에서 확인하고 설정 화면을 바로 열 수 있습니다.

### Windows (10/11, 64비트)
1. `setup.exe`를 실행합니다. 기본은 현재 사용자 설치라서 관리자 권한이 필요 없습니다. 포터블은 zip을 풀고 `ActionMacro.exe`를 실행합니다.
2. 코드 서명이 없어서 SmartScreen이 막으면 **추가 정보 → 실행**을 누르세요.
3. 관리자 권한으로 도는 프로그램(일부 게임·에뮬레이터)에 입력하려면 ActionMacro도 관리자 권한으로 실행해야 합니다.

## 확인한 것
- **macOS 자동 테스트:** 1215개 통과, 10개 건너뜀. 실제 Mac 에서 돌렸고, 화면 없는 환경이며 입력·캡처는 가짜입니다.
- **Windows 자동 테스트(GitHub Actions 러너):** 1207개 통과, 17개 건너뜀. 1개는 0.1.2 처럼 Windows 의 파일 잠금 방식 때문에 예상 실패로 둡니다.
- **실제 화면 플러그인으로 돌린 레이아웃·글꼴·타이틀바 검사:**
  - macOS 15 러너: 19개 통과
  - Windows 러너: 17개 통과
  - macOS 27 실기기: 19개 통과
- **macOS 27 실기기(Apple Silicon) 실제 마우스 입력:**
  - 상단바 빈 곳을 끌어 창을 옮겼습니다.
  - 더블클릭으로 화면 가득 확대했고, 한 번 더 해서 원래 크기로 돌아왔습니다.
  - 신호등 버튼과 상단바 항목의 세로 가운데가 맞는 것도 확인했습니다.
- 모든 패키지는 빌드 직후 자체 점검을 통과한 것만 올렸습니다.

## 알려진 제한
- macOS 전체 화면에서의 상단바와 macOS 26 에서의 모습은 아직 확인하지 않았습니다. 어색하면 알려 주세요.
- Windows 는 타이틀바 아래에 상단바가 있는 지금 모습 그대로입니다.
- Windows 배율 150% 와 여러 모니터(음수 좌표)는 아직 실기기에서 확인하지 않았습니다.
- Windows 배율 125% 에서 한 번, 글자 입력 단계가 첫 글자만 입력한 일이 있었습니다(0.1.2 에서 알림). 원인은 아직 모릅니다. 글자가 덜 들어가면 알려 주세요.
- macOS와 Windows 모두 코드 서명이 없습니다(위의 첫 실행 안내 참고).
- Intel Mac 패키지는 0.1.1부터 내지 않습니다. Intel Mac에서는 0.1.0을 쓰거나 소스에서 실행하세요(README 참고).
- Linux 패키지는 없습니다.
- 백그라운드 실행(`--headless`)은 Windows 패키지에서 콘솔 출력이 보이지 않습니다. 명령줄로 쓰려면 소스에서 설치하세요(README 참고).

포함된 서드파티 소프트웨어와 라이선스는 앱 안의 `THIRD_PARTY_NOTICES.txt`에 있습니다.
