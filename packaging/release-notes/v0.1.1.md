키 입력 단계로 아이디 같은 **글자를 그대로 입력**할 수 있게 했습니다.

## 바뀐 점

### 새 기능: 글자 입력
Key Input 단계의 속성 패널 맨 위 `Send`에서 **`Text`**를 고르고 `Text to type`에 적으면(예: `myid123`), 그 글자를 한 글자씩 입력합니다. 카드에는 `Type "myid123"`처럼 보입니다.

- 글자는 키보드 포커스가 있는 창에 들어갑니다. 바로 앞에 입력 칸을 누르는 Mouse Click 단계를 두세요.
- 줄바꿈은 Enter로, 탭은 Tab으로 입력됩니다.
- 입력하는 도중에도 일시정지와 긴급 정지가 바로 듣습니다.
- **Windows**: 글자를 키보드 키가 아니라 유니코드 문자로 보냅니다. 그래서 Caps Lock이나 키보드 배열과 상관없이 적은 대로 들어갑니다. 다만 키보드 신호를 직접 읽는 일부 게임이나 원격 데스크톱 프로그램은 이렇게 보낸 글자를 받지 않을 수 있습니다.
- **macOS**: 글자를 치는 동안만 입력 소스를 **ABC**로 바꿨다가 원래 소스로 되돌립니다. 그래서 한글 입력 상태에서도 `myid123`이 `ㅡㅛㅑㅇ123`으로 바뀌지 않고, 한글(`홍길동`)도 그대로 들어갑니다. 입력하는 동안 메뉴 막대의 입력 소스 표시가 잠깐 바뀝니다.
- 적은 글자는 시나리오 파일에 그대로(평문) 저장됩니다. 비밀번호에는 쓰지 마세요.

### 고친 점
- 이전에는 `Key or shortcut` 모드의 Keys 칸에 `myid123` 같은 단어를 적어도 저장되고, 실행할 때 오류로 멈췄습니다. 이제는 적는 즉시 키 이름이 아니라고 알려 주고 적용하지 않습니다. 글자를 입력하려면 `Text`를 고르라는 안내도 함께 나옵니다.

### 시나리오 파일 호환
- **Text 단계가 들어 있는 시나리오는 0.1.0에서 열리지 않습니다.** 0.1.1로 업데이트해서 여세요.
- Text 단계가 없는 시나리오는 0.1.0과 0.1.1 사이에서 그대로 주고받을 수 있습니다.

## 0.1.0에서 업데이트
- **Windows**: 새 `setup.exe`를 실행하면 기존 설치 위에 덮어씁니다. 포터블은 새 zip을 풀어 쓰면 됩니다.
- **macOS**: DMG의 `ActionMacro`를 `Applications`로 끌어 놓고 **대치**를 고릅니다. 첫 실행 허용(아래 2번)을 다시 해야 합니다. 앱이 임시(ad-hoc) 서명이라 권한도 다시 물을 수 있습니다. 이때는 **시스템 설정 → 개인정보 보호 및 보안**의 각 목록에서 옛 `ActionMacro` 항목을 지우고 다시 허용합니다.

## 설치와 첫 실행

### macOS (12 이상)
1. DMG를 열어 `ActionMacro`를 `Applications`로 끌어 놓습니다. 포터블은 zip을 풀어 `ActionMacro.app`을 원하는 폴더에 둡니다. DMG 안에서 바로 실행하지 마세요.
2. 처음 열면 *"Apple could not verify “ActionMacro” is free of malware…"* 경고가 나오고 열리지 않습니다. 앱에 Apple 개발자 서명과 공증이 없어서이고, 앱이 손상된 것은 아닙니다. 아래 둘 중 하나로 한 번만 허용하면 됩니다.
   - **시스템 설정에서**: 경고 창에서 **완료**를 누르고, **시스템 설정 → 개인정보 보호 및 보안** 맨 아래의 **그래도 열기**를 누른 뒤 암호로 확인합니다. 이 버튼은 방금 열려다 막힌 앱에만 한동안 보이므로, 안 보이면 앱을 한 번 더 열어 본 뒤 확인하세요.
   - **터미널에서**: 인터넷에서 받은 파일에 붙는 격리 표시를 지웁니다. 다른 폴더에 두었다면 경로를 그 위치로 바꿉니다. 그다음에는 평소처럼 열립니다.

     ```bash
     xattr -dr com.apple.quarantine /Applications/ActionMacro.app
     ```
3. **시스템 설정 → 개인정보 보호 및 보안**에서 `ActionMacro`를 허용합니다.
   - **손쉬운 사용**: 마우스·키보드 입력
   - **입력 모니터링**: 긴급 정지 단축키(Esc · Ctrl+Shift+S)
   - **화면 및 시스템 오디오 녹음**: 이미지 대기와 좌표 선택 돋보기

   빠진 권한은 앱의 **⋯ → Permissions…**에서 확인하고 설정 화면을 바로 열 수 있습니다.

### Windows (10/11, 64비트)
1. `setup.exe`를 실행합니다. 기본은 현재 사용자 설치라서 관리자 권한이 필요 없습니다. 포터블은 zip을 풀고 `ActionMacro.exe`를 실행합니다.
2. 코드 서명이 없어서 SmartScreen이 막으면 **추가 정보 → 실행**을 누르세요.
3. 관리자 권한으로 도는 프로그램(일부 게임·에뮬레이터)에 입력하려면 ActionMacro도 관리자 권한으로 실행해야 합니다.

## 확인한 것
- 자동 테스트 1199개 통과(화면 없는 환경, 입력·캡처는 가짜).
- 모든 패키지는 빌드 직후 자체 점검을 통과한 것만 올렸습니다. 이번에는 Windows 글자 입력에 쓰는 유니코드 입력 신호를 만드는 점검이 더해졌습니다.
- macOS(Apple Silicon) 실기기 점검 22단계 통과. 이번에 더한 것은 글자 입력입니다. 입력 소스가 ABC일 때와 한글 2벌식일 때 각각 `myid123`, `Ab1 x_Y!@`, `안녕하세요 홍길동 id123`을 입력해 적은 대로 들어가는 것을 확인했고, 입력 뒤에는 원래 입력 소스로 돌아왔습니다.
- **Windows 글자 입력은 아직 실기기에서 확인하지 않았습니다.** 특히 한/영이 한글 상태일 때 영문이 그대로 들어가는지 확인이 필요합니다.
