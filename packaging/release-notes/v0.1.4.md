클릭 단계가 이미지 대기로 찾은 위치를 누를 수 있게 되었습니다. 이제 버튼 이미지를 기다렸다가 그 버튼을 누르는 매크로를, 좌표를 찍지 않고 만들 수 있습니다. 두 OS 모두 해당합니다.

## 바뀐 점 (두 OS 공통)

### 클릭 단계: 찾은 이미지 누르기
Mouse Click 단계의 속성 패널 `Target position` 에서 **`Found image`** 를 고르면, 좌표 대신 이번 실행에서 마지막으로 Image Wait 단계가 찾은 이미지의 가운데를 누릅니다. 카드에는 `Click left at the found image` 처럼 보입니다.

- `Point` 를 고르면 전처럼 X·Y 좌표를 누릅니다. 적어 둔 X·Y 는 `Found image` 로 바꿔도 남아 있어서, 다시 `Point` 로 돌리면 그대로 돌아옵니다.
- 좌표 선택(`Pick from screen`, `Ctrl+P`)으로 점을 찍으면 `Point` 로 돌아갑니다.
- 찾은 위치는 클릭과 같은 좌표 단위입니다(macOS 는 포인트, Windows 는 물리 픽셀). 배율이나 Retina 화면에서 따로 계산할 것이 없습니다.

### 찾은 이미지가 없을 때
- 아직 찾은 이미지가 없으면 **아무 데도 누르지 않고** 콘솔에 경고(`Click skipped: no image has been found yet in this run`)를 남깁니다. 앞에 Image Wait 단계가 없거나, 나타나기를 기다린 이미지가 시간 안에 나오지 않아 `skip` 으로 넘어온 경우입니다.
- 나타나기를 기다린 이미지가 나오지 않으면, 그 전에 다른 이미지를 찾은 위치는 잊습니다. 엉뚱한 곳을 누르지 않기 위해서입니다. 사라지기를 기다리는 단계는 찾은 위치를 바꾸지 않습니다.
- 실행할 때마다 찾은 위치 없이 시작합니다. 앞선 실행에서 찾은 위치를 다음 실행이 쓰지 않습니다.

## 알아 둘 점 (Windows)
- **디스플레이 배율을 바꾸면 템플릿 이미지를 다시 찍으세요.** 템플릿은 찍은 배율에서만 찾힙니다. 0.1.3 실기기 점검에서 100% 에서 찍은 템플릿은 150% 에서 찾지 못했고, 150% 에서 찍은 템플릿은 125% 에서 찾지 못했습니다. 이미지 대기의 ROI 도 물리 픽셀로 넣습니다.
- 이미지 대기는 0.5초마다 화면을 확인합니다. 그래서 이미지가 나타나거나 사라진 뒤 다음 단계로 넘어가기까지 0.4~0.7초 걸립니다.

## 시나리오 파일 호환
- `Found image` 를 쓰지 않은 시나리오는 0.1.3 과 파일이 같습니다. 0.1.3 과 그대로 주고받을 수 있습니다.
- `Found image` 를 고른 클릭 단계가 든 시나리오는 **0.1.3 이하에서 열리지 않습니다.** 0.1.4 이상에서 여세요.

## 이전 버전에서 업데이트
- **Windows**: 새 `setup.exe`를 실행하면 기존 설치 위에 덮어씁니다. 포터블은 새 zip을 풀어 쓰면 됩니다.
- **macOS**: DMG의 `ActionMacro`를 `Applications`로 끌어 놓고 **대치**를 고릅니다. 첫 실행 허용(아래 2번)을 다시 해야 합니다. 앱이 임시(ad-hoc) 서명이라 권한도 다시 물을 수 있습니다. 이때는 **시스템 설정 → 개인정보 보호 및 보안**의 각 목록에서 옛 `ActionMacro` 항목을 지우고 다시 허용합니다.

## 설치와 첫 실행

### macOS (12 이상)
1. DMG를 열어 `ActionMacro`를 `Applications`로 끌어 놓습니다. 포터블은 zip을 풀어 `ActionMacro.app`을 원하는 폴더에 둡니다. DMG 안에서 바로 실행하지 마세요.
2. 처음 열면 *"Apple could not verify “ActionMacro” is free of malware…"* 경고가 나오고 열리지 않습니다. 앱에 Apple 개발자 서명과 공증이 없어서이고, 앱이 손상된 것은 아닙니다. 아래 둘 중 하나로 한 번만 허용하면 됩니다.
   - **시스템 설정에서**: 경고 창에서 **완료**를 누르고, **시스템 설정 → 개인정보 보호 및 보안** 맨 아래의 **그래도 열기**를 누른 뒤 암호로 확인합니다. 이 버튼은 방금 열려다 막힌 앱에만 한동안 보이므로, 안 보이면 앱을 한 번 더 열어 본 뒤 확인하세요.
   - **터미널에서**: 인터넷에서 받은 파일에 붙는 격리 표시를 지웁니다. 다른 폴더에 두었다면 경로를 그 위치로 바꿉니다. 그다음에는 평소처럼 열립니다.

     ```bash
     xattr -dr com.apple.quarantine /Applications/ActionMacro.app
     ```
3. **시스템 설정 → 개인정보 보호 및 보안**에서 `ActionMacro`를 허용합니다.
   - **손쉬운 사용**: 마우스·키보드 입력
   - **입력 모니터링**: 긴급 정지 단축키(Esc · Ctrl+Shift+S)
   - **화면 및 시스템 오디오 녹음**: 이미지 대기와 좌표 선택 돋보기

   빠진 권한은 앱의 **⋯ → Permissions…**에서 확인하고 설정 화면을 바로 열 수 있습니다.

### Windows (10/11, 64비트)
1. `setup.exe`를 실행합니다. 기본은 현재 사용자 설치라서 관리자 권한이 필요 없습니다. 포터블은 zip을 풀고 `ActionMacro.exe`를 실행합니다.
2. 코드 서명이 없어서 SmartScreen이 막으면 **추가 정보 → 실행**을 누르세요.
3. 관리자 권한으로 도는 프로그램(일부 게임·에뮬레이터)에 입력하려면 ActionMacro도 관리자 권한으로 실행해야 합니다.

## 확인한 것
- **macOS 자동 테스트:** 1230개 통과, 10개 건너뜀. 실제 Mac 에서 돌렸고, 화면 없는 환경이며 입력·캡처는 가짜입니다. "찾은 이미지 누르기" 테스트 15개는 실제 모델·파일 저장·실행 엔진·속성 패널을 거칩니다.
- **Windows 자동 테스트(GitHub Actions 러너):** 1222개 통과, 17개 건너뜀. 1개는 전처럼 Windows 의 파일 잠금 방식 때문에 예상 실패로 둡니다.
- **실제 화면 플러그인으로 돌린 레이아웃·글꼴·타이틀바 검사:** macOS 15 러너 19개, Windows 러너 17개, macOS 27 실기기 34개(새 테스트 포함) 통과.
- **Windows 10 실기기 점검(0.1.3, 노트북 1920×1080):**
  - 배율 150%: 전체 점검 29단계 중 27단계 통과, 2단계는 Caps Lock 을 한/영으로 바꿔 쓰는 설정 때문에 건너뜀. 클릭 오차 0px, 좌표 선택 → 클릭 0.3 논리 px.
  - 실제 화면 캡처로 이미지 대기: 배율 100% · 125% · 150% 에서 각 8/8 통과, 찾은 위치 오차 0px. 실제 메인 창의 실행 버튼으로도 확인했습니다.
  - 0.1.3 설치본 설치·실행·제거와 포터블 자체 점검 정상.
  - 배율 125% 글자 입력 40번 반복 모두 맞음.
- 모든 패키지는 빌드 직후 자체 점검을 통과한 것만 올렸습니다.

## 알려진 제한
- "찾은 이미지 누르기"는 자동 테스트로만 확인했습니다. 실제 화면과 실제 마우스로 누르는 것은 아직 확인하지 않았습니다. 엉뚱한 곳을 누르면 알려 주세요.
- macOS 전체 화면에서의 상단바와 macOS 26 에서의 모습은 아직 확인하지 않았습니다.
- Windows 는 타이틀바 아래에 상단바가 있는 모습 그대로입니다.
- Windows 여러 모니터(음수 좌표)와 Caps Lock 켬 상태의 글자 입력은 아직 실기기에서 확인하지 않았습니다.
- 0.1.2 에서 알린, 배율 125% 에서 글자 입력 단계가 첫 글자만 입력한 일은 0.1.3 점검에서 40번 반복해도 다시 나오지 않았습니다. 원인은 모릅니다. 글자가 덜 들어가면 알려 주세요.
- macOS와 Windows 모두 코드 서명이 없습니다(위의 첫 실행 안내 참고).
- Intel Mac 패키지는 0.1.1부터 내지 않습니다. Intel Mac에서는 0.1.0을 쓰거나 소스에서 실행하세요(README 참고).
- Linux 패키지는 없습니다.
- 백그라운드 실행(`--headless`)은 Windows 패키지에서 콘솔 출력이 보이지 않습니다. 명령줄로 쓰려면 소스에서 설치하세요(README 참고).
